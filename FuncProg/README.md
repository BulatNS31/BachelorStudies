# Functional Programming

This directory contains laboratory assignments exploring functional and logic programming concepts using Python and Prolog.

## Labs

- **Lab 1 (Python):** Implements list operations, Fibonacci-related calculations, and basic programming tasks.
- **Lab 3 (Prolog):** Explores logic programming through family relationships, house puzzles, racing problems, and virtual world scenarios.

## Languages

- Python (`.py`)
- Prolog (`.pl`)
