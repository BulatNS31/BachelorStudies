# Assembly Language

This directory contains programming assignments implemented in Assembly language (`.asm`).

## Tasks

- **Task 1:** Byte and word manipulation, word exchange, and equation solving.
- **Task 2:** Greatest common divisor (GCD), summation, and factorial calculation.
- **Task 3:** File writing, array summation, and finding unique elements.

PNG files contain screenshots illustrating the tasks and their results. `text.txt` is used for file-related operations.

## Language

- Assembly (`.asm`)
