# BachelorStudies

A collection of university laboratory assignments, programming exercises, and study materials completed throughout my bachelor's degree.

## Contents

### 1. Assembly
Assembly language programming assignments covering byte and word manipulation, arithmetic operations, factorial calculation, greatest common divisor (GCD), array processing, and file operations.

**Language:** Assembly

### 2. MathLogic
Implementations of Turing machines for string manipulation, including combining a surname with a birth date and appending initials.

**Language:** Python

### 3. BaseNetworks
Windows batch scripts demonstrating basic command-line operations, directory management, environment configuration, and system administration.

**Language:** Windows Batch

### 4. FuncProg
Laboratory assignments covering basic programming concepts, list operations, Fibonacci-related calculations, and logic programming problems involving family relationships, houses, racing, and virtual worlds.

**Languages:** Python, Prolog

### 5. Structural Data
Implementations of fundamental algorithms and data structures, including Bubble Sort, minimum element search, and Stack operations.

**Language:** Python

## Technologies

- Assembly
- Python
- Prolog
- Windows Batch

## Purpose

This repository serves as an archive of academic work, a reference for reviewing programming concepts, and a record of practical experience gained during my bachelor's studies.
