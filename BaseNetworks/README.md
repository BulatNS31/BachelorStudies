# Basic Networks and System Administration

This directory contains Windows batch scripts for basic system administration and command-line operations.

## Scripts

- **`copy_tree.bat`** — Copies directory trees.
- **`format_disk.bat`** — Performs disk formatting operations.
- **`local_env.bat`** — Configures local environment variables.
- **`parent.bat`** — Demonstrates parent process or directory-related operations.
- **`show.bat`** — Displays information in the command prompt.
- **`show_2.bat`** — Demonstrates additional command-line display operations.
- **`error.log`** — Stores error log information.

## Language

- Windows Batch (`.bat`)
